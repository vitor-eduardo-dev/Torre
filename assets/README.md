# Sistema de Inscrições da Torre

Aplicação web desenvolvida para organizar as inscrições dos turnos e funções da Torre, garantindo controle, estabilidade e facilidade no uso diário.  
O sistema já está **concluído e em produção**, sendo utilizado pela equipe para gerenciar funções, evitar conflitos e manter a organização das escalas.

---

## Funcionalidades

- Cadastro e gerenciamento de inscrições por turno  
- Controle automático de conflitos (evita duas pessoas na mesma função)  
- Sistema de validação interno para garantir consistência  
- Modo manual para ajustes pela equipe responsável  
- Layout simples e funcional  
- Integração com automações via **Google Apps Script**  
- Atualização em tempo real do status das funções

## Sobre o Desenvolvimento

O projeto foi criado para resolver um problema real:  
a necessidade de organizar funções e turnos sem sobrecarga manual, evitando duplicidade e erros de registro.

Todo o fluxo foi pensado para:

- ser simples para quem usa  
- ter lógica clara e rastreável  
- evitar conflitos automaticamente  
- permitir ajustes manuais quando necessário  
- funcionar de forma leve, rápida e acessível
